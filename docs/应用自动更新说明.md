# 应用自动更新

App 每次启动会静默读取更新清单；“我的”页面的“检查更新”可手动重试。发现新版本后，用户确认下载，App 校验 SHA-256、应用包名和 APK 签名证书，再交给 Android 安装器完成更新。Android 系统仍会要求用户确认安装；App 不会静默安装。

更新清单地址由 Gradle 属性 `appUpdateManifestUrl` 配置，必须是 HTTPS。正式版和内测版默认通过 GitHub Contents API 实时读取仓库 main 分支的 `updates/stable.json` 和 `updates/latest.json`，请求原始 JSON 响应；GitHub Release、raw.githubusercontent.com 和 jsDelivr 地址作为备用来源。APK 下载使用 GitHub Release。

可在构建时设置自定义更新源：

```powershell
.\gradlew.bat assembleRelease -PappUpdateManifestUrl=https://updates.example/latest.json
```

清单 JSON 格式：

```json
{
  "versionCode": 32,
  "versionName": "0.1.4",
  "apkUrl": "https://updates.example/suixinji.apk",
  "sha256": "APK 文件的小写 SHA-256 十六进制值",
  "changelog": "本次更新说明"
}
```

`versionCode` 必须大于当前应用版本。后续 APK 必须使用当前安装包的签名密钥或 Android 已认可的签名轮换证书，否则客户端会拒绝进入安装流程。Android 安装器也会再次执行平台签名校验。

验证命令：

发布时同步上传 Release 清单并更新仓库 updates 目录；apkUrl 使用带版本标签的固定地址，避免最新版本变化后下载包与清单 SHA-256 不匹配。内测清单仅在构建了同签名内测 APK 后更新。

```powershell
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:assembleDebug
```
