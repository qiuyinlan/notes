# 会员功能接入

会员 API 地址由 Gradle 属性 `membershipApiBaseUrl` 提供，必须是 HTTPS 根地址，不要包含 `/v1`。默认值是占位地址 `https://replace-with-membership-api.example`；接入真实服务时使用：

```powershell
.\gradlew.bat assembleRelease -PmembershipApiBaseUrl=https://your-membership-api.example
```

也可以在本机 `~/.gradle/gradle.properties` 中配置 `membershipApiBaseUrl=https://your-membership-api.example`。`BuildConfig.MEMBERSHIP_API_BASE_URL` 在构建时生成，仓库不保存服务端密钥。

会员中心位于“我的”页面。打开会员中心才会调用邮箱验证码接口；登录后会读取 `/v1/me` 和 `/v1/entitlements`，兑换和退出按服务端响应处理。访问令牌用 Android Keystore 的 AES-GCM 密钥加密后存于应用私有偏好设置。会员 API 不会接收本地笔记内容。

免费版允许离线使用；编辑器 `@` 功能可试用 20 次，整理仅开放“全部·顺序整理”，漫步仅开放随机，主题色入口转到会员中心。此类本地界面限制可被修改 APK 绕过，不能用来保护服务端资源。

构建和单测：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```
