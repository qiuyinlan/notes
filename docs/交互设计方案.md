# 随心记交互设计方案

## 目标

让每次点击、输入、滑动和保存都有明确反馈，让用户知道“发生了什么、下一步可以做什么”。动效服务于状态变化和空间关系，保持米色、白色、棕色的安静质感，不使用过度跳动或连续自动播放的动画。

## 统一交互原则

### 反馈层级

1. **即时反馈**：点击后 100ms 内改变图标、颜色或按压状态。
2. **过程反馈**：导入、备份、识别图片等耗时操作显示进度和当前步骤。
3. **结果反馈**：保存、删除、归类、恢复后显示短暂 Snackbar；重要操作提供撤销。
4. **状态反馈**：空状态、加载中、失败和完成状态都使用明确的图标与短句。

### 动效规范

| 场景 | 动效 | 建议时长 |
| --- | --- | --- |
| 按钮按下 | 缩放至 0.96，颜色略深 | 100ms |
| 页面进入 | 淡入并从右侧移动 16dp | 220ms |
| 返回上页 | 淡出并向右移动 16dp | 180ms |
| 卡片展开 | 高度与内容同步展开 | 220ms |
| 删除 | 向左滑出，随后列表补位 | 220ms |
| Snackbar | 从底部上移并淡入 | 180ms |
| 底部弹窗 | 从底部上移，背景遮罩淡入 | 240ms |

所有动效应尊重系统“减少动态效果”设置；关闭后保留状态变化，但移除位移和缩放。

## 全局交互

### 底部导航

- 当前页面图标使用棕色填充，非当前页面使用低对比度线性图标。
- 点击导航项时，图标做一次轻微缩放和回弹，不改变页面布局。
- 当前页面重复点击：回到该页顶部；首页重复点击：清除日期筛选并回到今天。
- 页面切换使用横向淡入，避免整页突然闪现。

### 左侧栏

- 左上角两条横线按钮始终可点击，点击后抽屉从左侧滑出。
- 抽屉打开时背景加半透明遮罩；点击遮罩、返回键或再次点击按钮关闭。
- 标签行按下时显示浅棕背景；长按进入多选模式，顶部出现“全选、删除、取消”。

### 按钮和图标

- 图标按钮必须有按压态和无障碍描述。
- 破坏性操作（删除、清空）使用棕红色确认按钮，并支持撤销。
- 只显示图标的按钮通过长按显示 Tooltip；三个点菜单保持独立，不与 Markdown 工具栏混用。

## 首页时间线

### 输入框

- 首页底部输入框固定悬浮，圆角白底和柔和阴影。
- 点击后编辑页从底部扩展到全屏，输入框自动获得焦点并弹出键盘。
- 输入框获得焦点时，工具栏贴在输入框上沿；失去焦点后工具栏回到底部。
- 首次输入显示“保存”加号按钮；点击保存后保留当前页面，不自动退出，另一个“完成”勾号负责保存并返回。

### 时间线卡片

- 卡片进入视口时轻微淡入，禁止连续瀑布动画。
- 长文本默认收起至约半屏；点击展开时平滑展开，双击进入编辑。
- 左滑卡片显示删除和归类操作，松手前显示预览，超过阈值才执行。
- 右侧评论入口显示为一个图标；已有评论不重复显示第二个入口。
- 删除后显示 Snackbar：“已删除 · 撤销”。

### 筛选

- 点击热力图日期后，首页顶部显示日期筛选条；点击关闭图标恢复全部记录。
- 筛选条出现和消失使用高度动画，时间线保持滚动位置可预测。

## 大屏编辑页

- 页面背景白色，文字区域不加外框，左右边距保持紧凑。
- 顶部左侧为勾号返回并保存；右侧三个点打开“复制全文、删除”等菜单。
- 光标进入正文后，Markdown 工具栏浮在输入框上方；工具栏横向滚动，不挤压正文。
- 点击粗体、斜体、删除线、下划线、荧光笔时：
  - 有选中文字则立即包裹选区；
  - 无选中文字则插入成对语法，并把光标放在中间；
  - 工具按钮短暂高亮，避免用户误以为没有生效。
- 输入 `- ` 后回车自动延续列表，再次空行回车结束列表。
- 标签实时变蓝并缩小字号；评论标记固定插在对应文字位置。
- 评论眼睛只负责展开/收起评论；双击评论跳回对应原文位置。
- 自动保存采用防抖：停止输入约 1.5 秒保存一次，顶部显示短暂“已保存”；保存失败显示可重试提示。
- 离开时若有未保存改动，弹出“保存并退出 / 放弃 / 继续编辑”。

## 评论交互

- 在光标所在位置点击评论，原文下一行插入评论标记并打开半屏输入面板。
- 面板顶部显示对应原文片段，避免用户忘记评论对象。
- 提交后评论框展开，显示评论文字和创建时间；点击眼睛收起为小图标。
- 支持一段原文多个评论，评论按创建时间排序。
- 时间线只显示评论图标；编辑页和预览页显示完整评论内容。

## 整理台

- 内容区域独立滚动，底部操作栏固定悬浮，不随笔记移动。
- 操作栏使用白底、明显灰色描边和阴影，与米色背景分离。
- 左右滑动切换当前记录，卡片跟随手指移动；超过阈值松手后切换，否则弹回。
- 跳过、归类、删除使用图标按钮；归类成功后显示下一条并更新进度。
- 删除后支持撤销；跳过的记录不在当前批次重复出现。
- 图片整理模式切换使用横向滑动过渡，并保留当前批次进度。
- 导入图片显示“已读取 / 总数”进度，解析失败的图片可单独重试。

## 漫步

- 首次进入随机选取一条笔记，显示“范围第 x / y 篇”。
- 左右滑动按创建时间前后浏览，卡片跟随手指移动；到边界显示轻微回弹和边界提示。
- 底部悬浮栏固定，包含上一条、编辑、下一条；按钮使用灰色描边。
- 点击“重新随机”时先淡出当前内容，再淡入新内容，避免文字瞬间替换。
- 双击正文进入编辑，返回后保持原来的漫步位置。

## 标签

- 标签图形进入页面时按网格顺序淡入；颜色只用于区分，不承担状态含义。
- 点击标签进入对应笔记页；右上角搜索图标展开搜索框。
- 长按标签进入多选模式；拖动经过标签时连续选中，顶部显示已选数量。
- 标签右侧下箭头打开“编辑标签、查看上级、查看下级”；菜单使用圆角白底和轻阴影。
- 新建笔记时自动插入当前标签路径，保存后返回标签页并定位到新笔记。

## 信件

- 首页信件使用白底信封卡片和数字角标；没有待收信件时显示 0，不隐藏入口。
- 点击信封卡片进入信件列表，列表卡片使用轻微翻页式进入效果。
- 新建信件使用日期选择器；确认日期后显示“将在 yyyy-mm-dd 打开”。
- 到期信件打开时使用信封展开动画，正文从信封中淡入。
- 返回手势只返回信件列表，不直接退出应用。

## 我的、导入与备份

- 热力图滑动月份时，月份标题和网格同步移动；双击热力图回到今天。
- 导入页面先选择来源，再显示书籍多选和目标标签；扫描、导入、去重分别显示阶段进度。
- 备份成功显示文件名和保存位置；恢复前显示将覆盖当前数据的确认提示。
- 恢复完成后显示记录、标签、信件数量，并提供“查看首页”按钮。

## 空状态与错误

- 空状态必须提供下一步按钮，例如“开始记录”“导入备份”“选择文件夹”。
- 网络导入失败显示具体原因和“重试”，不只显示“no notes found”。
- 权限被拒绝时说明用途，并提供“去设置”入口；用户拒绝后仍可使用本地记录功能。
- 任何异常操作都不得清空当前输入，草稿先保存在本地。

## 验收清单

- 所有点击都有按压反馈，所有耗时操作都有进度或加载状态。
- 整理台和漫步底部栏始终悬浮，滚动时不遮挡最后一条内容。
- 编辑、评论、标签、信件的返回路径一致，系统返回键不会直接退出到桌面。
- 开启系统减少动态效果后，功能和层级仍然清晰。
- 在低端设备连续快速滑动、导入大量数据时无明显卡顿和重复提交。
